# Data Sample

This folder contains a **small representative sample** (2 images per class) of the
full crop-disease image dataset used for validation in the paper (`My_Data.zip`,
originally 429MB / 1,543 images across 22 classes).

The full dataset was intentionally **not** committed to this repository to keep
the repo lightweight and avoid Git/GitHub size and bandwidth limits. Classes
represented in the full dataset:

- Anthracnose on Cotton
- Becterial Blight in Rice
- Brownspot
- Common_Rust
- Cotton Aphid
- Flag Smut
- Gray_Leaf_Spot
- Healthy Maize
- Healthy Wheat
- Healthy cotton
- Mosaic sugarcane
- RedRot sugarcane
- Rice Blast
- Sugarcane Healthy
- Wheat Brown leaf rust
- Wheat black rust
- bollworm on Cotton
- cotton mealy bug
- cotton whitefly
- maize ear rot
- maize fall armyworm
- maize stem borer
